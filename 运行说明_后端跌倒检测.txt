人员跌倒检测——运行说明
========================

功能
----
站立时显示绿色“正常”，摔倒并保持约 7 帧后显示红色“摔倒”。
重新站直并保持约 10 帧后自动解除报警，也可点击“手动复位报警”。

首次安装
--------
1. 打开 PowerShell。
2. 进入项目目录：
   cd "C:\Users\AAA\Desktop\1"
3. 安装依赖：
   python -m pip install -r requirements.txt

启动
----
1. 在项目目录运行：
   python fall_backend.py
2. 浏览器打开：
   http://127.0.0.1:5000
3. 停止服务：在 PowerShell 中按 Ctrl+C。

测试
----
不连接摄像头也可以验证核心判定：
   python -m unittest -v test_fall_detection.py

使用建议
--------
- 摄像头尽量固定，最好能拍到肩、髋和腿部。
- 保证人物身体占据画面一定区域，避免逆光和严重遮挡。
- 当前版本按单人场景设计，多人同时出现时只会跟踪主要人物。
- 本项目仅作辅助检测，不能替代人工看护或专业安全设备。

阈值调整
--------
参数位于 fall_detection.py 的 FallDetector.__init__：
- fall_angle：越大越灵敏，也越容易把弯腰判成跌倒，默认 38°。
- fall_frames：报警前需连续命中的帧数，默认 7。
- recover_frames：站起后解除报警所需帧数，默认 10。
